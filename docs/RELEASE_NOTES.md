# 纸笺 v0.2.0 — 预览版

新增 GitHub 自动更新与手动检查，让后续升级在应用内完成。

## 新增

- 「设置 → 软件更新」：自动检查开关、手动检查、正式版/预览版频道。
- 开启后在启动时和每 6 小时检查发布，自动下载新版本和发布说明。
- 下载进度、签名验证、安装就绪提示，以及断网/限流后的重试。
- 下载完成后，点击「安装并重新启动」才会安装；安装前等待当前窗口的任务写入。
- macOS Universal、Windows x64 EXE/MSI 更新包签名，验证签名绑定版本，拒绝包篡改和版本替换。

## 升级

v0.1.0 没有更新器，请先手动安装本版本。之后在设置开启自动更新即可；本仓库目前发布预览版，请同时开启「接收预览版本」。自动更新默认关闭。

下载 macOS Universal DMG / App 压缩包，或 Windows x64 EXE / MSI。每个平台提供 SHA-256 校验、源提交号；新增 `.sig` 与 `latest.json` 供更新器使用。

## 当前限制

- 更新签名不等于系统发行者签名：安装包尚未做 Apple 公证或 Windows Authenticode 签名，系统仍可能显示未知发行者提示。
- 更新检查与提醒依赖应用运行；关闭窗口留在托盘可继续，完全退出后停止。下载缓存仅保留到应用退出。
- 默认发行包没有云服务配置。Supabase 登录/同步尚未完成真实多设备验收。
- 仍为预览版，包含虚构示例任务。自动构建和签名测试不代表完整的双平台实机升级验收，请先用非重要数据体验并保留备份。

所有发布包由 CI 从同一标签构建，源码经过公开前审计与密钥扫描。
