# 纸笺 v0.1.0 — 预览版

首个公开预发布版本：Tauri + React 待办应用，包含任务列表、快速记录、提醒设置、标签、浅色/深色主题和桌面组件。

## 下载

- macOS：Universal DMG 或 `.app.tar.gz`，包含 Apple Silicon 与 Intel。
- Windows x64：NSIS `.exe` 或 MSI 安装包。
- 每个平台提供 SHA-256 校验文件和包含源代码提交号的 `SOURCE` 文件。

## 当前限制

- 安装包未签名，macOS 未公证；系统可能显示未知发行者提示。尚未提供自动更新。
- 默认发行包不包含云服务地址、API key 或用户数据。Supabase 登录/同步仅作为开发中的可选接入层，尚未完成真实多设备验证。
- 提醒依赖应用运行；完全退出后不保证触发。重启时会尝试补发最近 24 小时错过的提醒。
- 桌面组件与数据持久化仍处于预览阶段。通过自动构建不代表已完成所有平台的实机验收。
- 当前包含虚构示例任务。请先用非重要数据体验并自行保留备份。

源代码经过公开前检查和密钥扫描；发行包由 CI 从相同标签构建。
